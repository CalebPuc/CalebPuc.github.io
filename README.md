- **Projects:** a Java multiplayer game engine with 237 automated tests, a ROS 2 patrol robot built on a Kinova arm, a Unity dungeon crawler, operating-system and 16-bit CPU projects, an Arduino design-challenge robot, and a silicon wafer etch with LabVIEW lab automation
- **Skills, honors, and a short bio**
- **Resume:** a downloadable PDF

## How it's built

A single hand-written page with no frameworks or build step:

- **HTML and CSS:** responsive layout for phone and desktop, with automatic light and dark themes
- **JavaScript:** an animated canvas in the header that sketches the "Highway in the Sky" guidance tunnel from my NASA project; it respects the reduced-motion setting
- **Hosting:** GitHub Pages, with a custom domain set by the `CNAME` file
